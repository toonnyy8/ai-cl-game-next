# 簡化格鬥遊戲：核心系統設計

Oct 27, 2026 · @Jen-Hung Huang

## 設計目標

只用攻擊鍵與 SP 鍵兩個按鍵，而且完全沒有防禦。深度不來自按鍵數量，而來自「什麼時候出手、什麼時候換招」。

- **沒有防禦**：守方只能靠插招與換招應對，不出手就只能挨打，因此不需要額外的反龜縮獎懲。
- **攻擊與 SP 預設互相抵銷**：只有「換招」能打破抵銷，勝負由換招的時機決定。
- **角色個性來自 SP**：每個角色有自己的開頭 SP 與中間 SP，決定其節奏、距離與連段路線。

## 名詞定義

開頭 SP 與中間 SP 是完全不同的兩組招式；中間 SP 插入連段的位置，決定下一次的開頭 SP。

| 名詞 | 定義 |
| --- | --- |
| 攻擊 | 攻擊鍵的招式。必須命中（或被抵銷）才能接續下一步。 |
| NA | 中立 → 攻擊。 |
| 開頭 SP（NS） | 中立 → SP。每招是一段節奏、段數不一的連續技，短至一擊、長至四段。施放時不改變指針。 |
| 中間 SP（AS） | 攻擊命中後 → SP，與開頭 SP 完全不同的招式。施放的同時改寫指針。轉折招。 |
| SA | SP → 攻擊（在開頭 SP 的段與段之間插入攻擊）。轉折招。 |
| SP 指針 | 決定下一次開頭 SP 是哪一招，只能由中間 SP 改寫。 |
| 延續 | 不換類型的接續：攻擊 → 攻擊、開頭 SP 的下一段。不算轉折招。 |

## 出招規則

攻擊靠命中延續，SP 不論中否都能延續；改變下一輪起手的唯一方法，是在攻擊命中後插入中間 SP。

1. **攻擊必須命中才能接續。** 打空或被打斷，連段就此結束。
2. **開頭 SP 不論是否命中都能接續。** 例如 NS\[1\] → SP\[2\] → SP\[3\]，每一段照角色設定的節奏出招，段與段之間可以插入攻擊（SA），用來控制距離、節奏與傷害。
3. **開頭 SP 不改變指針。** 只用 SP 起手、卻從不讓攻擊命中的玩家，會一直使用同一招開頭 SP，容易被讀透。
4. **攻擊命中後按 SP = 中間 SP。** 會立刻施放中間 SP，並改寫指針。在連段中的不同位置插入，會決定下一次的開頭 SP。
5. **SP 序列中也一樣。** 在開頭 SP 序列裡，只要「攻擊命中 → SP」，這個 SP 就是中間 SP，會施放並改寫指針。

這帶來一個核心取捨：中間 SP 同時決定「這一輪追擊夠不夠痛」和「下一輪的起手威脅」，兩者很少剛好是同一招。指針應清楚顯示在畫面上，讓守方讀得到。

## 相剋與判定規則

攻擊對 SP 預設抵銷；轉折招帶一次霸體，只對同類與另一招轉折有效，藉此打破抵銷。

### 相剋關係

1. NA 與 NS 互相抵銷：雙方都不受傷，並各自接續後續出招。
2. AS 剋 NS。
3. SA 剋 NA。
4. AS 與 SA 互撞時，後手剋先手：較晚出手的一方贏。

### 判定規則

1. **攻擊對 SP，且都不是轉折招**：抵銷，雙方無傷、繼續。攻擊方視同命中，可以接下一下。
2. **同類相撞**（攻擊對攻擊、SP 對 SP）：先打到的贏。
3. **轉折招（AS、SA）帶一次霸體**，只對兩種情況有效：
   - 同類的招：AS 吃 SP，SA 吃攻擊。
   - 另一招轉折：這條讓後手贏。
4. **轉折招對上異類的非轉折招**：霸體無效，照規則 1 抵銷。

霸體只在「起手到自己的判定出現」之間有效，不能維持到自己打中為止。先手的判定打在後手的起手上被吃掉，這時先手的霸體已經結束，後手的判定才打到先手，後手贏。後手出得太晚、先手的判定已經打到人，就只是被打中。

### 判定表

| 我方＼對手 | NA、攻擊延續 | NS、SP 延續 | AS | SA |
| --- | --- | --- | --- | --- |
| NA、攻擊延續 | 先打到者贏 | 抵銷 | 抵銷 | SA 贏 |
| NS、SP 延續 | 抵銷 | 先打到者贏 | AS 贏 | 抵銷 |
| AS | 抵銷 | AS 贏 | 後出者贏 | 後出者贏 |
| SA | SA 贏 | 抵銷 | 後出者贏 | 後出者贏 |

## 情境推演

平行出招時，先換招的人贏；但對手若立刻跟著換，後手反過來贏。

### 平行出招

以 NA\[1\] → A\[2\] → A\[3\] 對上 NS\[1\] → SP\[2\] → SP\[3\] 為例：

- **兩邊都照打**：每一步都是攻擊對 SP，一路抵銷，雙方打完自己的序列，誰都沒受傷。
- **攻擊方在第 2 步換成 SP（AS）**：變成 SP 對 SP\[2\]，AS 的霸體吃下 SP\[2\]，攻擊方贏。
- **SP 方在第 2 步換成攻擊（SA）**：變成攻擊對 A\[2\]，SA 的霸體吃下 A\[2\]，SP 方贏。
- **雙方都換**：AS 對 SA，後出手的一方贏。

換招時機本身就是一場猜拳：早換能抓住只會照打的對手，但會被反應快、立刻跟著換的對手反過來吃掉。

### 連段空隙中的插招

守方被連段時，可以在空隙裡插 NA 或 NS；攻方則在空隙選擇 AS 或 SA。

| 攻方＼守方 | NA | NS |
| --- | --- | --- |
| AS | 抵銷，進入平行出招 | 攻方贏 |
| SA | 攻方贏 | 抵銷，進入平行出招 |

守方插的招若與攻方同類，就會被轉折招的霸體吃掉；類型不同則抵銷脫身，回到「誰先換招」的局面。被連段因此不是單純挨打，翻盤機會內建在系統裡。

## 待定事項

核心相剋已定案；以下細節還需要決定或實測。

- [ ] 中間 SP 插在連段不同位置時，分別對應到哪一招開頭 SP。
- [ ] 同一招中間 SP 在一個連段內能否重複出現（避免「攻擊 → SP → 攻擊 → SP」無限循環）。
- [ ] 同類相撞「先打到者贏」需要的各招發生速度數值。
- [ ] 兩招轉折招在同一幀出手時的處理（建議互相抵銷）。
- [ ] 移動與方向輸入的規則。
- [ ] 消極打法的對策：退在外圍等對手打空再懲罰。可考慮讓開頭 SP 多帶前進、場地做小並設牆。

設計槓桿：每招中間 SP 可以做成沒有空隙的真連段（穩但傷害低），或刻意留空隙（守方能插招，但收益高），以此區分角色個性。
